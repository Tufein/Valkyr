# Valkyr 5.7.0

## More room for your games

- Fold the library search field, quick filters, view controls and console chips into one compact bar with the arrow in the search field. This frees vertical space for browsing and scrolling, especially on landscape handheld screens.
- Your search text, active filters and selected view stay in place. The compact bar shows the search and active filter count; tap it to reopen the controls, or press **Y** to search again.
- Collapsing closes the keyboard and returns controller focus to the games. The collapsed state survives screen recreation, and the controls work in both portrait and landscape.
- Updated help text in all seven supported languages.

## Install

Download **`Valkyr-release.apk`** for the normal app. It updates the existing Valkyr installation and keeps your data. Android 10 or newer is required.

**`Valkyr-debug.apk`** is the separate test app. SHA-256 checksums are included in **`SHA256SUMS.txt`**.
