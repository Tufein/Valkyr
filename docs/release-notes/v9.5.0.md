# Valkyr 9.5.0

**Find, download and organise retro games on your Android phone or handheld.** This release is the *a backup you cannot lose* theme: every cloud backup can now be copied to a second cloud, and restored from there when the main one is gone.

## What's new

- **Second copy**: set up a second cloud, a WebDAV server or an S3 bucket, under *Cloud → Backup*. Every backup is sealed once and written to both, with the same name and the same keep rule, so the two always hold the same set.
- **Still copied when the main cloud is down**: the second copy is made even when the main upload fails, and a failing copy never fails the main backup. Each says plainly what went wrong.
- **Restore from either**: the backup list has a *Main cloud / Second copy* switch, and a restore from the copy uses the same passphrase and the same safety checks.
- **Cloud hub card**: the second copy shows its own status and the time of its last copy.

## Safe and honest

- The login of the second cloud stays on this handheld, like the backup passphrase: it is not part of an app backup and a restore never touches it. *Stop copying* removes it; backups already there stay.
- The copy is tested before it is written to, so a half-typed address is never used, and a plain `http://` address over the internet gets the same warning as the main cloud.
- Not built: SMB and SFTP (they need a client library and a real server to prove), device sync and the other shared documents to more than one cloud, and certificate pinning for the second cloud.
- No new permissions and no database change.

All new text is in the seven app languages, and the five READMEs point at this release.
