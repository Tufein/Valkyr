# Valkyr 9.7.0

**Find, download and organise retro games on your Android phone or handheld.** This release is the *launches that tell the truth* theme: when a game starts and stops again within seconds, Valkyr now says so, instead of leaving you with a silent failure and a play-time number that is wrong.

## What's new

- **"It started and stopped again"**: if Valkyr is back in front within 15 seconds of a launch, the game page shows a card with how long it lasted and the usual reasons: a missing BIOS file, an emulator that needs another core, or a file that still has to be unpacked.
- **One tap to the cause**: the card's *Check this game* opens the game's readiness check, which names the missing BIOS file or the unsupported format. *Dismiss* hides the card, and it also goes away by itself after the next launch.
- **Honest play time**: a start that ended within 15 seconds did not run, so it is no longer saved as a session. Time played, session counts and the synced play history from 9.4 only hold real play.

## Safe and honest

- Nothing is read from the emulator's private files and nothing is changed: the card only reports what Valkyr itself saw, the time between the launch and the return.
- Not built: a launch report that names the emulator version and recipe, and feeding the new-handheld checklist from the same check; both need a handheld with several emulators to prove.
- No new permissions and no database change.

All new text is in the seven app languages, and the five READMEs point at this release.
