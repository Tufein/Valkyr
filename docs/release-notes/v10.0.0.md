# Valkyr 10.0.0

**Find, download and organise retro games on your Android phone or handheld.** Version 10 is a deliberately big release with one theme: *the handheld lab and the travelling library*. Six additions (the lab alone holds five tests), each small enough to use in a minute.

## What's new

- **Handheld lab** (Tools): test the hardware you play on. The *controller test* shows every button you press, both sticks, both triggers and the D-pad, and can measure stick drift: let go for three seconds and it tells you whether the sticks rest in the middle. The *screen test* fills the display with black, white, red, green, blue, a grey ramp and a grid to show dead pixels, burn-in and uneven light. The *touch test* asks you to swipe until every square on the screen lights up, and the *speaker test* plays a short tone on the left, the right or both speakers. *Battery and heat* shows charge, temperature and voltage live, and says when the device is getting hot. Try the Konami code in the controller test.
- **Profiles that travel**: with Device sync on, your profiles (what each one hides) follow you between handhelds by name, and the newest edit wins. The PIN and the active profile stay on each device, and deleting a profile on one handheld does not delete it on the others.
- **Sync to both clouds**: Up next, progress, notes, play history and profiles can also sync with the second cloud from 9.5. *Sync documents here too* is off until you switch it on, and nothing is removed from either cloud.
- **Power search**: type `console:snes`, `c:"game boy"`, `tag:hack` or `is:fav` in the search box next to a title and they become filters. Tap the hints under the search box to add them; titles that contain a colon still search as text.
- **File fingerprint**: on a game you own, the game page can calculate the CRC32, MD5 and SHA-1 of the game's files and copy them, so you can compare a dump with a DAT or Redump entry. It only reads, and you can stop it.
- **Launches name their tools**: the *It started and stopped again* card now says which emulator, core and version the game was started with.

## Safe and honest

- The lab only looks and measures: nothing is saved, nothing is changed and nothing leaves the device. Fingerprints are only read.
- Syncing never removes anything: profiles and documents merge as a union or by the newer edit. The second cloud takes part only when you switch it on.
- This release has not run on a real handheld yet; it is covered by unit tests and CI. Please use *Report a problem* if a test screen, the stick drift verdict or the search words misbehave on your device.
- Not built: SMB and SFTP, a play-time reminder, trimming screenshots, the recipe name in the launch report, and putting the library sync itself on two clouds.
- No new permissions and no database change.

All new text is in the seven app languages, and the five READMEs point at this release.
