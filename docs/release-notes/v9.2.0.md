# Valkyr 9.2.0

**Find, download and organise retro games on your Android phone or handheld.** This release is the *more to discover* theme: a bigger, more informative "Best games" list from RetroAchievements, and game manuals from more places than just your own RomM server. It is built on 9.1.0.

## New in 9.2.0

- **Best games covers more systems**: 35 more RetroAchievements consoles are recognised, from the C64 and ZX Spectrum to the Amiga, PC-88/98, Game & Watch and Arduboy. Each console lists its top 100 games (was 40), kept in a small cache for a week.
- **More facts about each game**: RetroAchievements' detailed answer now also gives hardcore player counts, release year and genre, and the game list adds leaderboard counts. No extra requests are made for these — they come from the call that already counted players.
- **Rank the way you want**: choose *Rank by hardcore* as well as *Rank by players*, and sort the shown rows locally by rank, title, year, points or players. Filter by what you own — all games, on device, in a source, or missing. Sorting and filtering cost no requests and never change the rank the numbers earned.
- **Manuals from the web**: besides your RomM server, Valkyr asks ScreenScraper for its `manual` media and the public Internet Archive for a PDF scan, in that order. A fourth way is pasting a direct link. Each provider has its own switch (*Settings → Library → Advanced → Manual sources*), and a definite "no manual" is remembered for a month so the same game is not asked about again and again.

## Safe and honest

- Every stored manual keeps its provider name, and the game page says which sources were asked when nothing turns up. A rate limit, an exhausted quota, a refused login or being offline is never treated as "no manual" — those sources are tried again later.
- ScreenScraper's existing gates, daily quota and credential handling are reused: its password is removed before a manual address is stored and put back only on the outgoing request. Internet Archive lookups check at most two items per game.
- Manual downloads keep the same rules as before: a temporary file, never replacing one you already have, a total size cap that removes the oldest manuals first, safe folder names and https-only redirects that stay at the provider.

All new text is in the seven app languages, and the five READMEs describe the new sources and the wider list.
