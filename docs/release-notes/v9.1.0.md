# Valkyr 9.1.0 (pre-release)

**Find, download and organise retro games on your Android phone or handheld.** This pre-release is the *Sources tracker* theme: one place to see what every source is actually doing, where your games came from, and a short list of announce addresses for your own torrents. It is built on 9.0.0.

## New in 9.1.0

- **Sources tracker** (*Sources → Sources tracker*, also under More and Tools): every configured source of every console in one list, worst first. Each row shows its scan health and scan history, plus the download track record — average speed, share that worked and a failure trend over the last 30 days. **Scan** rescans only that address; other sources are left alone. *Export track record* shares the numbers without leaking addresses, paths, keys or file names: labels are a source kind plus a short, non-reversible tag.
- **Where a game came from**: a download remembers its first source and the source it was switched to, both after an automatic retry and after a manual change. Downloads show *From …* next to *Switched to …*, and a game's About tab names the source too. The provenance survives a restart and travels in backups (Room schema 18).
- **Torrent trackers** (*Settings → Torrents → Torrent trackers*): keep your own announce addresses, switch them on or off, add or remove them, and test the http(s) ones. The list is added to every torrent Valkyr fetches — magnets, `.torrent` files, metadata-cache hits and the debrid route. The trackers your sources already list are still used. A `udp://` address is only syntax-checked: the app says plainly that it cannot test a UDP announce here.
- **A longer track record**: `files/source_track.json` now keeps the last twelve outcomes per source (when, worked or failed, bytes and why), written atomically. Old files still load; a 30-day trend is derived from the timeline instead of only the current counters.

## Fixed while building this pre-release

- libtorrent4j needs an `AnnounceEntry`, not a plain string, when adding a tracker to a handle.
- The trackers setting is a link row to its own screen, so search ids stay unique and the Downloads settings card stays within the handheld's row limit.
- Lint no longer sees `getString()` calls through `LocalContext` in the new tracker screens.

## What is in this download

This pre-release ships **`Valkyr-debug.apk`** only: a separate app with its own data (`com.tufein.valkyr.debug`), so it can sit next to your normal Valkyr. Android build 95, version 9.1.0-debug. Checksums are in `SHA256SUMS.txt`.

Install it by opening the APK on Android 10 or newer and allowing "install unknown apps" if Android asks. Your normal Valkyr data is untouched; use *Settings → Back up* and *Restore backup* there if you want to try this build with your sources.

All 2,391 JVM unit tests pass, and `assembleDebug` plus `lintDebug` are green.
