# Valkyr 9.3.0

**Find, download and organise retro games on your Android phone or handheld.** This is a polish release: a full pass over the app removed false "no manual" answers, fixed ranking edge cases and tightened a handful of layouts. It is built on 9.2.0.

## Fixed and improved

- **Manuals tell the truth**: when a source has no manual, the game page now says so; when ScreenScraper is rate-limited, out of quota, refusing a login or offline, it says that source could not be reached instead. Unavailable is never cached as a month-long "no manual".
- **Manuals come back faster**: an automatic manual-with-game download stops at the first source that has a file instead of asking every source first. A failed download keeps its row, so the same manual can be tried again.
- **Manual panel and link dialog**: a loading line while the web lookup runs, the icon and title on one row like the other cards, and an inline error that keeps the dialog open until a pasted link is valid.
- **Best games ranks correctly**: a hardcore ranking no longer mistakes an old cache for a complete one, the hardcore refine fetches hardcore counts (not player counts), and sorting by year now uses the release date that only the detailed answer carries. Sort and filter choices survive a refresh, and the download/wish counts match the actions.
- **Layout fixes**: the header's trailing controls get their intended gap, Torrent Trackers uses the same Settings surface as its sibling screens, and the empty "Best games" screens scroll in a short landscape window with large text.
- **Steadier background work**: a manual lookup that fails can no longer take the app down, and concurrent manual settings writes no longer lose each other's updates.

## Safe and honest

- A pasted manual link is checked before the dialog closes: http(s) only, with local and loopback addresses rejected. LAN addresses still work for RomM and self-hosted manuals.
- ScreenScraper credentials are still stripped from stored addresses and added only to the outgoing download. Manual files keep the existing temporary-file, size-cap and no-overwrite rules.
- No new permissions, no new network endpoints, and no change to how games or saves are stored.

All new text is in the seven app languages, and the five READMEs point at this release.
