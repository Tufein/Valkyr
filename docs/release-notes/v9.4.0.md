# Valkyr 9.4.0

**Find, download and organise retro games on your Android phone or handheld.** This release is the *played on every handheld* theme: your play history now travels with the cloud sync, so a game you played on one handheld shows its time on the other.

## What's new

- **Play history travels**: finished play sessions are synced through the same cloud folder as Up next and progress, one small document per profile. Sessions are merged as a union, so a session is never counted twice and nothing is lost, in whatever order the handhelds sync. A session that is still running never travels.
- **Played on…**: each session is named after the handheld it was measured on, and a game's *Time played* panel lists the handhelds it was played on once there are two or more.
- **Play history card in the Cloud hub**: total time, sessions and the number of handhelds, shown once cloud sync is set up and there is something to show.
- **In your backups**: the app backup now carries the play history of the active profile. A restore adds sessions to what was played here and never replaces them.

## Safe and honest

- The document holds only game keys, start and end times and handheld names: no paths, no accounts, no titles. A broken or implausible row is skipped, never the whole history, and a file from a newer app is left alone.
- The history is bounded like the local file (the newest 4,000 sessions), and a sync that fails never stops the library sync.
- No new permissions, no database change, and nothing is sent anywhere you did not already configure.

All new text is in the seven app languages, and the five READMEs point at this release.
